# Contribution Guidelines

Please note that this project is released with a [Contributor Code of Conduct](code-of-conduct.md). By participating in this project you agree to abide by its terms.

This catalog is written in a librarian voice: facts about a work (form, themes, publication, place in the genre), not a diary of likes.

### Notes

If an entry has no catalog note, add a short impersonal one. Do not write first-person recommendations ("I liked this", "my favourite", "highly recommend"). Do not sign notes with a GitHub handle.

Useful notes mention:

- form (novel, trilogy, novella sequence, film, series)
- setting and central problem
- relationship to other works (adaptation, sequel, same universe)
- a standard English title, with the original title in parentheses when the work was not written in English

### New suggestions

Please ensure your pull request adheres to the following guidelines:

- The entry should contain title and author (or director) links, first publication or release year, a rating, a publisher or IMDb description, and a short catalog note.
  - For books, copy the description and rating from [Goodreads](https://www.goodreads.com) and link to the Goodreads entry.
  - For movies and TV shows, copy the description and rating from [IMDb](https://www.imdb.com) and link to the IMDb entry.
- Use the following format:

```
[title](link) (year) *by [author](link)* [rating]

Catalog note: form, themes, and place in the genre.

<details>
  <summary>Description</summary>

  > Summary of book/film etc here
</details>
```

- Check spelling and grammar.
- Add the entry in the correct section, in alphabetical order. If the section is unclear, use the general Science Fiction section. Categories for TV shows and movies can be taken from the IMDb page.
- The author link should point to the author's [Wikipedia](https://en.wikipedia.org) page. If no such page exists, use the author's [Goodreads](https://www.goodreads.com) page. If that does not exist either, leave the author name in plain text.
- Start the description with a capital and end with a full stop/period.
- Search previous suggestions before making a new one, as yours may be a duplicate.
- Make an individual pull request for each suggestion.
- The pull request and commit should have a useful title.
- If you are adding a movie, add categories as you see fit, using inline code ticks, in this format:

```
Categories: `ai` `action` `not about batman`
```

Thank you for the suggestion.
